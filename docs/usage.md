# 拾词使用说明

## 启动和划词

安装 .NET 8 Desktop Runtime（Windows x64）后，完整解压发布包，双击 `Shici.exe`。程序需要能写入它所在的文件夹，不要只拷贝 EXE。

在支持可访问文本选区的应用里，用鼠标拖选文字或双击单词。点击浮钮「中文」译为中文，「English」译为英文。选择文字本身不计数、也不发送翻译请求。

没有浮钮时，保持选区，使用主窗口底部显示的兼容快捷键。默认尝试 Ctrl+Alt+T，被占用时改用 Ctrl+Alt+Shift+T。手动输入框按 Enter 自动选择方向，Shift+Enter 换行。

卡片可滚动查看完整释义和词根资料，支持朗读、复制释义、固定和手动加入生词本。原形是词形还原结果，与历史词根不是同一个概念。未收录的词根会明确提示。

## 自动收词和复习

同一词第 4 次成功查询自动入本。有依据的不同词形尽量合并计数；同形多义时可能有歧义。查看已保存的卡片、朗读和复习不会增加计数。

中文词被译为单个英文词时，会尝试补充英文词典信息并合并。句子和长短语不自动入本，可手动收藏。

“我的生词本”支持搜索、按列排序、双击看卡片和保存个人笔记。“今日复习”先显示正面，翻面后再自评。记住时按 1、3、7、14、30、60 天安排复习；遗忘时重置并在 10 分钟后再出现。打开复习页可刷新到期列表。

## 导出和备份

导出文件写入程序旁的 `exports`：

- TSV：适合 Excel / WPS，包含词条、释义、查询次数、见过的词形、复习日期和笔记。
- Markdown：可以在 Typora 中阅读和整理。
- Anki TSV：两列“单词 / 释义及笔记”，导入时选择 Basic、Tab 分隔、关闭 HTML。复习进度不会随之导入。

退出程序后，备份整个 `data` 文件夹即可保留学习记录。迁移到另一台电脑时，请复制完整程序文件夹。`vocabulary.json.bak` 是前一次保存的备份。程序没有内置云同步。

`translation-cache.json` 包含查询文字和释义，`vocabulary.json` 包含计数、笔记和复习日期。这些文件都属于你的私人学习资料，请不要随 Issue 上传。

## 联网和兼容性

ECDICT 词典查询可离线完成；中译英和词典外的内容通过 MyMemory 查询，只发送相应的文字和翻译方向。每日匿名免费额度以服务商为准，当前为 5,000 字符。程序不提交邮箱，不调用上传语料接口。

最大查询长度是 1,200 字符，长内容会按 UTF-8 字节限制分段。翻译可能受语境、词典数据和网络服务质量影响。

自动取词依赖 Windows UI Automation 3。扫描 PDF、图片、受保护文字、部分编辑器和较高权限窗口可能不支持。兼容快捷键可能模拟 Ctrl+C，随后在剪贴板未被其他操作更新时恢复原内容；自动划词本身不改剪贴板。

主窗口可暂停划词。关闭窗口后留在托盘；右键托盘“退出”才会停止。再次双击 EXE 可以唤回已有窗口。没有设置开机自启。
